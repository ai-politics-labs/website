# 발기인 대시보드

기존 aiparty.kr 디자인 시스템에 직접 추가한다. `/dashboard`는 온라인 동의서 누적 접수 수와 시·도별 인원·전체 대비 비율을 공개한다. 개별 발기인 정보를 조회하지 않는다.

## Reference lock

- 주 기준: 기존 Layout.astro / index.astro. Pretendard, 흰색·#0e0e0d 테마, stone 계열, 검은 기본 동작, pill 버튼을 유지한다.
- Refero Ui(shadcn), c14c0a94-1037-449e-bf5b-4cb972656ac7: 얇은 테두리·14px 카드 반경·절제된 숫자 위계만 적용한다. 외부 폰트를 들여오지 않는다.
- Refero Linear Changelog, 11d3e58a-87d7-4a9a-bbf5-720f4fd3ffc6: 어두운 테마의 표면 구분과 그림자 없는 테두리만 적용한다.
- Refero Pop Site analytics, 5d24f428-3248-4212-81b3-54d11c565443: 요약 수치 다음 상세 분포를 배치한다.
- Refero Visitors, ff49a3d1-c880-4d1f-b335-07d93801e115: 지역 데이터의 빠른 스캔을 위한 우측 정렬 숫자와 작은 제어기를 적용한다.

| 결정 | 출처와 역할 | 이유 |
|---|---|---|
| 전체 발기인 수 우선, 지역 상세 뒤 | 사용자 요청, Pop Site | 요청한 두 정보를 가장 빨리 파악 |
| 17개 시·도 전체와 기타 표시 | 실제 주소 스키마 | 미분류 값을 누락하지 않고 전체 분모 유지 |
| 표 안 회색 막대와 비율 숫자 병기 | Visitors 데이터 위계, 기존 무채색 | 색상에 의존하지 않고 상대 크기 비교 |
| 모바일 한 열, 데스크톱 두 열 | craft-details 터치·접근성 | 17개 행의 읽기와 화면 폭 보장 |
| 오류 시 0으로 대체하지 않음 | 실제 데이터 제약 | 연결 실패와 실제 0명 구분 |

개인정보 조회용 테이블 권한을 넓히지 않고 집계 전용 RPC만 호출한다. 비율의 분모는 기타를 포함한 전체 접수 수이며, 접수 검증이나 중복 제거를 별도 수행한 인원 수로 표현하지 않는다.
