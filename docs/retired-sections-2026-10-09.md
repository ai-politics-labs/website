# 별도 콘텐츠·캠페인 제거 계획

요청일: 2026-10-09

## 남길 범위

메인(`/`), 로그인(`/auth`), 내 초대 현황(`/account`), 발기인 현황(`/dashboard`), 계정 개인정보 안내(`/community/privacy`), 발기인 관리자(`/admin`). 공개 동의 발기인 19명 카드와 기존 가입·인증·추천·집계 기능을 유지한다.

## 제거할 범위

창당선언문, ATLAS2049 소개와 Vault, `/revote` 및 모든 하위 페이지·캠페인 관리자. 이 페이지들만 사용하는 레이아웃·컴포넌트·이미지·브라우저 스크립트·설정도 현재 빌드에서 제거한다.

## 실행 순서

1. 기존 테스트를 실행해 유지할 가입·인증·추천·집계 동작을 확인한다.
2. 발기인 현황이 캠페인의 상수 파일에서 가져오는 Supabase 연결 설정을 공통 파일로 분리한다.
3. 제거 대상의 현재 파일 내용을 `archive/retired-sections-2026-10-09/`로 옮긴다. 기존 미커밋 수정도 함께 보존한다.
4. 활성 소스·빌드 설정·운영 문서의 남은 연결을 정리한다.
5. 테스트와 빌드를 실행해 경로가 17개에서 6개로 줄었는지, 제거 경로·공개 에셋이 산출물에서 빠졌는지 확인한다. 메인과 발기인 현황도 실제 화면에서 확인한다.

독립 검토에서 확인한 추가 조건: `archive/`는 TypeScript와 Tailwind 자동 검색 대상에서 제외한다. 기존 캠페인 테이블의 개인정보 격리를 확인하는 SQL 테스트는 제거하지 않는다. 계정 삭제 요청은 현재 `/account`의 독립된 기능이므로 유지한다.

## 보존할 데이터

Supabase 테이블·접수 데이터·동의서·파일 저장소·기존 SQL 이력은 변경하지 않는다. 현재 삭제 요청 및 계정 개인정보 기능도 유지한다. 이번 요청은 사이트 화면과 배포 파일을 정리하는 범위이며 데이터 삭제를 수행하지 않는다.

## 완료 및 검증

- 제거 대상 27개 파일의 현재 내용을 보관하고 SHA-256 일치 여부를 확인했다. `archive/retired-sections-2026-10-09/manifest.json`에서 원래 경로와 해시를 확인할 수 있다.
- 빌드 결과는 유지 대상 6개 페이지뿐이다. 로컬 HTTP 확인에서도 6개 페이지는 200, 제거한 11개 페이지와 대표 에셋 2개는 404를 반환했다.
- 메인 프로필 카드에는 공개 동의 및 개인정보 동의가 있는 19명의 마스킹 이름과 실제 등록 직업을 표시했다. `src/data/public-founders.json`은 조회 시점의 정적 명단이며, 재조회용 SQL은 `db/queries/public-founders-masked.sql`이다.
- 실제 화면에서 19개 카드, 이름 마스킹, 직업 표시, 1280px 및 375px 화면의 가로 넘침 없음과 긴 직업명 잘림 없음을 확인했다. 카드 높이는 106px이다.
- 발기인 현황 화면에서 전체 111명과 17개 지역의 집계가 정상 조회되는 것을 확인했다.
- 테스트 43개, 프로덕션 빌드 및 변경사항 공백 검사가 통과했다. DB 변경이나 배포는 수행하지 않았다.

변경 파일: 메인 페이지·공개 발기인 명단·조회 SQL, 공통 Supabase 설정·발기인 현황 페이지, Astro/TypeScript/Tailwind 설정, 커뮤니티 스타일, README 및 위 보관 폴더.
